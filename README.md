## Competition Performance

**Competition:** [House Prices — Advanced Regression Techniques](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques)

| Metric | Result |
|---|---:|
| Best-performing model | CatBoost |
| Out-of-fold RMSE | 0.123416 |
| Public leaderboard score | **0.12416** |
| Recorded leaderboard rank | **1,188** |
| Models evaluated | 6 |
| Validation | 5-fold cross-validation |

The project evaluates six regression approaches, including gradient-boosted trees and regularized linear models. Additional experiments investigate hyperparameter optimization, feature engineering, outlier sensitivity, and ensemble performance.

CatBoost achieved the lowest cross-validation error and was retained as the final submission model.
